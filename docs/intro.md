# Rust Fundamentals

Bitácora de estudio completa, estructurada y en español basada en el libro oficial
[*The Rust Programming Language*](https://doc.rust-lang.org/book/) (the Rust Book).

Este libro digital agrupa los **20 capítulos** del recorrido oficial de Rust, organizados como un
**Cargo Workspace** donde cada capítulo cuenta con:

*   📖 **Guía teórica** exhaustiva en español (este módulo de documentación, `docs/`).
*   🧩 **Código idiomático y ejecutable** (`chapters/<capítulo>`).
*   🧪 **Retos prácticos** con tests unitarios y doctests (`exercises/<ejercicio>`).

Navega por el menú lateral para comenzar con el [Capítulo 01: Primeros Pasos](ch01_getting_started.md).
